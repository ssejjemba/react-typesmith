# ReactTypeSmith

An AI-powered tool to refactor React JS/JSX into clean, type-safe TypeScript with organized structure and best practices.

## Features
- Type inference and interface generation
- Separation of concerns with function splitting
- AI-generated human-readable comments
- Defensive coding and render loop optimization
- Uniform variable naming and configurable folder structures
